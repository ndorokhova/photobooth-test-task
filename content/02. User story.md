# User story

## US-01. Отправка фотографии на электронную почту

> **Как** пользователь фотокиоска, **я хочу** отправить сделанную фотографию на указанный адрес электронной почты, **чтобы** получить её электронную копию.

## Критерии приемки
1. Пользователь может выбрать одну фотографию, сделанную в текущей сессии.    
2. Пользователь может указать адрес электронной почты.    
3. Перед отправкой пользователь должен подтвердить согласие на обработку данных.    
4. При некорректном формате email пользователь получает сообщение об ошибке и может исправить значение.    
5. После отправки заявки на получение фотографии по электронной почте пользователь получает подтверждение, что заявка принята системой к обработке.    
6. Если пользователь не получил подтверждение принятия заявки, он может повторить отправку или вернуться к выбору фотографии.    
7. После получения подтверждения о принятии заявки пользователь может завершить работу с фотокиоском или выбрать другой способ получения фотографии.
